# Examples

Each example uses your notification.dev project. Android/iOS examples use local
native SDKs; Flutter and Expo bridges consume released native packages:

- [Android](android-example/README.md): open `android-example/` in Android Studio.
- [iOS](ios-example/README.md): prepare the Swift package, then open the Xcode project.
- [Flutter](flutter-example/README.md): configure providers, then run `flutter run`.
- [Expo](expo-example/README.md): configure providers, then build a development client with `npx expo run:android` or `npx expo run:ios`.

The apps demonstrate identity, tags, email/push preferences, events, permissions, sync state, and notification opens. Use a disposable project for testing.
